# Hemant Sharma — Professional Resume Website

A lightweight, static resume site. The public website lives in `docs/`; project planning files and source resume documents remain outside that directory.

## Preview locally

Open `docs/index.html` in a modern browser. The site has no install step or external runtime dependencies.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the repository's default branch and the `/docs` folder, then save.
4. After the Pages build completes, open the published URL and review the page, links, mobile layout, and print output before sharing it.

Only files in `docs/` are intended for publication. Keep private data, source PDFs, and planning files outside that directory. Publish personal details only after confirming they are accurate and approved for public display.

## Before sharing the public URL

- [ ] Confirm the profile, work history, education, certifications, and contact links match the owner's approved resume.
- [ ] Check that only public, approved details are present in `docs/`; do not copy source PDFs or planning files there.
- [ ] Confirm GitHub Pages publishes the default branch's `/docs` directory.
- [ ] Review the site at phone and desktop widths, use keyboard navigation, and verify readable color contrast.
- [ ] Check all contact/profile links and use the browser's print or save-to-PDF action to review the complete resume.
